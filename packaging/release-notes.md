### Install SoundForm V2.0

1. Download **SoundForm-V2.0-Setup-x64.exe** from the assets below and run it. The same installer is included in **SoundForm-V2.0-Windows-x64.zip**.
2. Follow the setup prompts and open **SoundForm V2.0** from the Start menu. Setup also offers a desktop shortcut.

Supports 64-bit Windows 10 and 11. Python and the app dependencies are included. The app and installer are unsigned. Uninstall from Windows Settings.

Core geometry and directional audio analysis run locally. Experimental AI pavilion generation requires your own `ANTHROPIC_API_KEY` and internet access.
