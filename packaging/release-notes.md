First portable Windows release of Soundform.

### Download and run

1. Download **Soundform-Windows-x64.zip** below. The automatically generated Source code downloads are for developers.
2. Extract the entire ZIP.
3. Open **Soundform/Soundform.exe**. Keep the `_internal` folder beside it.

No Python installation is needed. Built for 64-bit Windows 10/11; Mac is not supported by this package. The app is unsigned.

### Included

- Directional audio analysis and metaball point generation.
- Surface Delaunay and Voronoi meshes, circulation openings and uniform/sound-weighted thickening.
- Rhino curve import, viewport drawing, box selection and keyboard deletion.
- Layer/object export and Soundform desktop/taskbar branding.

Core geometry and analysis run locally. Experimental AI pavilion generation requires your own `ANTHROPIC_API_KEY` and internet connection. No developer credentials are included.

The automated packaged checks passed, and the author manually checked the Windows app. A SHA-256 checksum is attached alongside the ZIP.
