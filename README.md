# SoundForm V2.0

SoundForm analyzes directional audio and uses it to generate architectural geometry.

## Install on Windows

1. Open [GitHub Releases](https://github.com/LC1795/FinalProjectGD-UofC-2026/releases) and download **SoundForm-V2.0-Setup-x64.exe**. If you downloaded **SoundForm-V2.0-Windows-x64.zip**, extract it first and open the installer inside.
2. Follow the setup prompts. The installer adds a Start menu shortcut and offers a desktop shortcut.
3. Open **SoundForm V2.0** from the Start menu.

The installer supports 64-bit Windows 10 and 11 and includes all app dependencies. You can remove the app from Windows Settings.

For build instructions, see [Windows packaging](packaging/README.md).
